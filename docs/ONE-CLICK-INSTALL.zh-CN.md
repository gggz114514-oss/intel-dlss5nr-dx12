# DX12 通用安装指南

当前入口为 [完整安装与卸载说明](../INSTALL.md)。下载完整安装 ZIP，解压后运行 `Install.cmd`；从源码仓库启动请用根目录 `Install-NR.cmd`，它下载并校验同一完整包。

选择赛博朋克 `bin/x64/Cyberpunk2077.exe`、巫师三 `bin/x64_dx12/witcher3.exe` 或死亡搁浅导演剪辑版 `ds.exe`。退出游戏再安装／卸载；不要手动删除游戏自带 FidelityFX DLL。

这取代此前要求在用户电脑上安装 Python / CMake / Vulkan SDK 的私有桥构建流程。开发者仍可使用 [源码构建说明](DX12-DEVELOPMENT.md)。
