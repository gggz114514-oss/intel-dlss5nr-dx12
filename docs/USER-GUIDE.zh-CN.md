# DX12 通用安装指南

v0.7.2 预发行版完整解压后运行 `Setup.cmd`。选择实际游戏 EXE，在同一个窗口执行检查、安装或卸载。游戏退出后再操作，备份位置以完成窗口为准。

燕云国服选择 `yysls.exe`，赛博朋克选择 `Cyberpunk2077.exe`，巫师三选择 `bin/x64_dx12/witcher3.exe`。具体步骤和外推倍率设置见 [安装与卸载](../INSTALL.md)。

仓库根目录的 `Install-NR.cmd` 仍下载固定的 v0.4.0 公开包。需要其他迭代时，直接从 [版本索引](ITERATION-ARCHIVE.md) 选择对应 ZIP。
